# Tiny Finder

Tiny Finder is a free Flutter learning app for kids ages 3 to 7. It helps children explore real objects, match memory cards, and sort numbers or letters with playful train activities.

## MVP

- No login
- No backend
- No ads
- Local progress storage
- Find Explorer, Number Train, Letter Train, and Memory Game
- Stars, badges, progress, parent gate, and parent settings
- Animal, shape, and color memory decks
- English, Malay, Mandarin, and Tamil app language setting
- Native text-to-speech pronunciation for prompts and learning words

## Development

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

The debug APK is written to `build/app/outputs/flutter-apk/app-debug.apk`.
